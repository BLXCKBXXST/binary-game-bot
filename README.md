# Binary Game Bot

Пользовательский скрипт для [Cisco Binary Game](https://netacad.sadlab.su/games/binary/). Автоматизирует прохождение игры и добавляет несколько дополнительных режимов.

## Возможности

- Автоматическое решение задач без искусственной паузы между партиями.
- Подсказка для нижней строки с настройкой прозрачности.
- Остановка при достижении заданного счёта без превышения цели.
- Детонатор 🧨 и баклажан 🍆 для решения нижней строки с анимацией.
- Мини-игра Flappy 🎮: за каждую пройденную трубу решается одна строка.
- Перетаскиваемая панель управления.
- Номер версии в меню и диагностический JSON по кнопке «📋 Лог».

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. **[Установите Binary Game Bot](https://raw.githubusercontent.com/BLXCKBXXST/binary-game-bot/main/Binary_Game_Bot.user.js)** и подтвердите установку в Tampermonkey.
3. Откройте [Binary Game](https://netacad.sadlab.su/games/binary/) и нажмите на левый нижний угол экрана, чтобы показать панель.

## Управление

| Кнопка | Действие |
| --- | --- |
| ▶ / ⏸ | Запуск и пауза автофарма |
| 💡 | Подсказка и настройка её прозрачности |
| 🎯 | Установка целевого счёта (0 — без ограничения) |
| 🧨 | Показать или скрыть детонатор |
| 🍆 | Показать или скрыть баклажан |
| 🎮 | Flappy-режим |
| — | Скрыть панель |
| ✕ | Выключить скрипт |
| 📋 Лог | Сохранить диагностический JSON |

Прозрачность подсказки регулируется кнопками **− / +**, в том числе удержанием, и сохраняется между перезагрузками страницы. В автофарме партии выполняются отдельными задачами браузера; при отсутствии MessageChannel используется обычный таймер.

## Версия 3.16

Устранено накопление уже завершённых React-строк, из-за которого обновления Redux дорожали на поздних уровнях. Активные строки и игровой reducer не меняются. Убрано общее двухсекундное ограничение между разными уровнями и добавлена защита от решения устаревших копий строк после очистки доски.

Методика, измерения и ограничения проверки описаны в [benchmarks/v3.16.md](benchmarks/v3.16.md). Скорость зависит от процессора, загрузки браузера и ограничений фоновых вкладок; полностью уснувшая вкладка не может продолжать фарм.

[Анализ дальнейшего ускорения на мобильных устройствах](benchmarks/mobile-speed-analysis.md) содержит распределение измеренных затрат, варианты сокращения отрисовки и план проверки на телефоне. Предлагаемые изменения пока не реализованы; мобильные результаты не измерялись.

Проверки без браузера: `node tests/farm-regression.cjs`. Проверка сохранённого завершённого прогона: `node tests/verify-benchmark.cjs <candidate.json>`.

## Обновления

Tampermonkey проверяет обновления по ссылке на этот репозиторий. Для получения новых версий должна быть включена проверка обновлений в настройках расширения.

Скрипт предназначен для страницы `https://netacad.sadlab.su/games/binary/*` и зависит от внутреннего устройства игры, поэтому изменения сайта могут повлиять на его работу.
