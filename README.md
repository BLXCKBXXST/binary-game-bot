# Binary Game Bot

Пользовательский скрипт для [Cisco Binary Game](https://netacad.sadlab.su/games/binary/). Автоматизирует прохождение игры и добавляет несколько дополнительных режимов.

## Возможности

- Автоматическое решение задач с настраиваемой задержкой.
- Подсказка для нижней строки с настройкой прозрачности.
- Остановка при достижении заданного счёта без превышения цели.
- Детонатор 🧨 и баклажан 🍆 для решения нижней строки с анимацией.
- Мини-игра Flappy 🎮: за каждую пройденную трубу решается одна строка.
- Перетаскиваемая панель управления.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. **[Установите Binary Game Bot](https://raw.githubusercontent.com/BLXCKBXXST/binary-game-bot/main/Binary_Game_Bot.user.js)** и подтвердите установку в Tampermonkey.
3. Откройте [Binary Game](https://netacad.sadlab.su/games/binary/) и нажмите на левый нижний угол экрана, чтобы показать панель.

## Управление

| Кнопка | Действие |
| --- | --- |
| ▶ / ⏸ | Запуск и пауза; при запуске открывается настройка задержки |
| 💡 | Подсказка и настройка её прозрачности |
| 🎯 | Установка целевого счёта (0 — без ограничения) |
| 🧨 | Показать или скрыть детонатор |
| 🍆 | Показать или скрыть баклажан |
| 🎮 | Flappy-режим |
| — | Скрыть панель |
| ✕ | Выключить скрипт |

Задержка и прозрачность регулируются кнопками **− / +**, в том числе удержанием. Настройки сохраняются между перезагрузками страницы.

## Обновления

Tampermonkey проверяет обновления по ссылке на этот репозиторий. Для получения новых версий должна быть включена проверка обновлений в настройках расширения.

Скрипт предназначен для страницы `https://netacad.sadlab.su/games/binary/*` и зависит от внутреннего устройства игры, поэтому изменения сайта могут повлиять на его работу.
