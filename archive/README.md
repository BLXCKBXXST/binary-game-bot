# Архив версий

Здесь лежат сохранённые копии скрипта. Рабочая версия для установки и автоматических обновлений — [Binary_Game_Bot.user.js](../Binary_Game_Bot.user.js) в корне репозитория.

- **3.8** — исходный файл до добавления настроек задержки и прозрачности.
- **3.9** — настройки задержки автофарма и прозрачности подсказки; добавлены адреса автообновления.
- **3.10** — исправлено расположение Flappy на ПК.

История коммитов Git также хранит изменения версий 3.9 и 3.10. Архивные файлы предназначены для сравнения и ручного отката: не устанавливайте их одновременно с основной версией.

Ранние версии 1.x–3.7 описаны в переписке, но исходных файлов этих версий здесь нет. Восстанавливать их по описаниям и выдавать за оригиналы не будем.
