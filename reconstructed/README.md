# Реконструкции ранних этапов

Это **не найденные оригинальные релизы**. Версии 1.0, 2.0 и 3.0 собраны заново по общей логике сохранившегося исходника 3.8. Номера обозначают условные этапы развития, а не подтверждённые исторические версии.

- **1.0** — минимальный интерфейс и попытка автоматического решения.
- **2.0** — предыдущий этап плюс подсказка.
- **3.0** — предыдущий этап плюс настройка целевого счёта.

**Важно:** это экспериментальные иллюстрации эволюции проекта. Они не проходили проверку в браузере и не гарантированно совместимы с текущими Redux-действиями игры. Не устанавливайте одновременно с рабочим скриптом. Для использования выбирайте подтверждённые версии из [archive](../archive), а для автообновления — основной скрипт в корне репозитория.

Файлы не включены в историю Git задним числом: дата их коммитов отражает реальную дату реконструкции. Исторические даты и исходники ранних релизов неизвестны.
